## Implemented contract

- Gate 0 routes work through active recurrence signatures, prior safe evidence,
  same-contract sibling inventory, canonical ownership, unsafe retry
  boundaries, and an executable barrier or reviewed NotApplicable result.
  Delegated tasks must carry the applicable safe response before the delegated
  agent's first tool call.
- Contract-equivalent generic assertions, content identity, repository
  evidence, Markdown/link parsing, and explicit test-context mechanics have one
  declared owner. Capability semantics remain local.
- The root runner, common harness, executable Case, capability support, fixture,
  and mock roles are non-overlapping. Exact runtime evidence replaces source
  inference and fails closed for missing, unexpected, duplicate, unexecuted, or
  failed cases.
- Protocol-update, bootstrap, and quick-adoption hotspots now emit exact child
  Case results. The temporary executable-fixture list, legacy-owner list, and
  legacy evidence module are absent.
- `test-harness-modularity` was appended at 2,824 bytes, LF, UTF-8 without BOM,
  with its Git blob identity verified at the linked capability checkpoint. The
  three predecessor definitions and compatible terminal-ledger prefix remain
  unchanged.
