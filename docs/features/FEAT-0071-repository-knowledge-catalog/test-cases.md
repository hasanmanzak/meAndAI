## Required coverage

- Generic repository usefulness without meAndAI or a consumer profile.
- Exact semantic identity, relation provenance, ambiguity, and separation from
  the governance Rule Catalog.
- Closed declarative profile schema and upstream ownership of reusable logic.
- Canonical snapshot identity, deterministic JSON, and compatibility behavior.
- SQLite deletion/rebuild equivalence, bounded query, full-text behavior, and
  corruption/schema mismatch handling.
- React-only presentation, headless parity, accessibility, performance, and
  absence of UI-owned semantics.
- Common [FEAT-0067](../FEAT-0067-evidence-acquisition-managed-consumer-integration/README.md)
  provider completeness/status preservation without duplicated acquisition
  behavior.
- Read-only hostile-input containment and immutable consumer distribution.
