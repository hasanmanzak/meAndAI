## Required coverage

- Exact committed-base tree and binary blob authority.
- Generic instruction roots, complete current known-surface compatibility
  vectors, nested scope, required local references, cycles, unlinked seeded
  candidates, arbitrary-unseeded negative controls, and benign controls.
- Canonical ordinal serialization and host-independent graph digest.
- Missing, malformed, linked, escaping, over-budget, case-ambiguous, Unicode-
  ambiguous, invalid-encoding, and drifted evidence.
- Graph-derived strategy projection without mutation-authority expansion.
- Exact dispatch/manifest/marker/issue/prompt/recovery/completion identity.
- Legacy proposal and completed-consumer compatibility.
- Independent final-graph closure, authorized edge retirement, and semantic-
  actor omission detection.
- Exact protected application, product, test, binary, asset, and runtime modes
  and blobs.
- Project-neutral fixture names; no production consumer-specific path coupling.
- One immutable meAndAI self-consumer fixture showing that the protocol
  repository follows the same graph contract without a repository-name bypass.
- Non-root JSON string payloads remain opaque, JSON instruction roots retain
  discovery and containment, and unterminated/control-bearing scalar masking
  fails closed.
