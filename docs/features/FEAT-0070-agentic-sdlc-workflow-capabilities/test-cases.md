## Required coverage

- Alias/schema identity, ambiguity, versioning, immutable binding, complete
  admission/input-output/effect/grant/directive/role/context/evidence/
  concurrency/recovery/adapter metadata, and effect containment.
- Extensible workflow families remain classification only and cannot create
  semantics, effects, or grants.
- Canonical directive applicability, project overlays, non-applicability, and
  no copied rules.
- Gate admission, workflow-run separation, recurrence ambiguity, stale state,
  and evidence-derived assessment.
- Actor/role/grant separation, writer lease, reviewer independence, and
  orchestrator non-authority.
- Exact context/handoff fields, redaction, expiry, retry boundary, result,
  findings, and base/head consistency.
- Single-agent default, material activation, worker ceiling, read-only
  parallelism, no parallel writers, and recursive-delegation denial.
- Exact-grant provider effects and immutable upstream-owned consumer use.
